# Contributing

1. Discuss the production goal and references before generating content.
2. Keep all new written material and CI output in English.
3. Do not commit private source assets or licensed packs. Use the private `corosolto/studio-assets` repository for those files.
4. Run `npm ci`, `npm run check`, `npm run check:asset-gen` and `npm run smoke:pack`.
5. Include research, fixed-camera evidence, limitations and review ownership for visual changes.
6. Do not trigger paid generation, deployment or client integration from a pull request.

Historical documents in `studies/` are preserved as evidence and may remain in their original language. New studies must be written in English.
