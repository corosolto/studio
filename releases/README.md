# Releases

Public files here may describe review status, provenance expectations and owner decisions. They are not a payload store and the client does not consume this directory automatically.

The genuine `map/lajes/0.1.0` candidate manifest and its hashed binaries stay in the private candidate output created by `tools/build-lajes-pack.mjs`. No public manifest is committed for that private payload, and no public model path is implied.

A schema-valid candidate is only a review input. It is not owner-approved, runtime-promoted, published or deployed. Those states require separate explicit records and actions; immutable binaries are tracked privately or published to approved storage with SHA-256 only after the required review.
